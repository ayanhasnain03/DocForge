Anxious Model 0.5 is a **7B** open-weight checkpoint tuned for cautious planning, uncertainty estimates, and structured refusal when evidence is thin.

## At a glance

| Property | Value |
| -------- | ----- |
| Parameters | 7B dense |
| Context | 32 768 tokens |
| Training tokens | ~2.1T pretrain + mid-train |
| Languages | English primary; code-adjacent |
| License | Apache 2.0 |
| First release | 2026-03-12 (`0.5.0`) |
| Current patch | `0.5.2` (2026-06-01) |

## When to use it

- Incident triage and postmortem drafts
- Policy / runbook writing with explicit assumptions
- Research notes that need calibrated confidence
- Tool-assisted planning where overconfidence is costly

## When not to use it

- Hard latency SLAs under ~80 ms TTFT
- Multimodal image or audio input
- High-throughput chat where refusals hurt UX
