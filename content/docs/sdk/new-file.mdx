This page demonstrates every MDX component available in the admin editor. Use the block inserter to add Tabs, Callouts, Accordions, and more.

## Tabs

Add a **Tabs** block, set the tab labels list, then add a **Tab** child for each label. Labels and Tab blocks must match and stay in the same order.

<Tabs items={["npm", "pnpm", "yarn"]}>
  <Tab value="npm">
    ```bash
    npm install @harc/sdk
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm add @harc/sdk
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn add @harc/sdk
    ```
  </Tab>
</Tabs>
